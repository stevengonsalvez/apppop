## What's inside?

The template itself is built on top of some very powerful tools and frameworks, including:

- 🚀 React - A JavaScript library for building user interfaces
- 💾 Supabase - Open source Firebase alternative with authentication, database and Storage
- 💸 Stripe - for products and payments
- 📈 Google Analytics - for tracking and analytics
- 📦 Material UI - for beautiful, responsive components
- 🎨 Framer Motion - for smooth animations and transitions
- 🎨 Tailwind CSS - for utility-first CSS styling
- 🔍 Microsoft Clarity - for user behavior analytics and heatmaps
- 🛠️ Sentry - for error tracking and performance monitoring
- 🎨 Easy Theming for Material UI - customize your app's look and feel effortlessly
- 📱 Ionic - for app store distribution
- 📱 Capacitor - for building native iOS and Android apps
- 🗂️ TanStack Query - for state management
- 📄 React Markdown - for rendering markdown documentation and blogging






Because we're using React with Supabase as the full-stack framework, we can leverage a lot of features to build our SaaS in record time, including:

- 🔐 Full-stack Authentication - Email verified + social Auth out of the box
- ⛑ End-to-end Type Safety - TypeScript throughout the entire stack
- 🤖 Background Jobs - Run cron jobs in the background or set up queues
- 🚀 Easy Deployment - Deploy to any modern hosting platform




You also get access to a diverse, helpful community if you get stuck or need help.
